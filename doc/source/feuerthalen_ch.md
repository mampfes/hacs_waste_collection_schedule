# Gemeinde Feuerthalen

Support for schedules provided by [Gemeinde Feuerthalen](https://www.feuerthalen.ch/umwelt/entsorgung/abfall.html/275).

Source for waste collection in Feuerthalen, Canton of Zurich, Switzerland.

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: feuerthalen_ch
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: feuerthalen_ch
```

## How to get the source arguments

No configuration needed: Feuerthalen publishes one waste calendar for the whole municipality.
