# Ville de Saint-Basile-le-Grand

Support for schedules provided by [Ville de Saint-Basile-le-Grand](https://www.villesblg.ca).

Source for villesblg.ca waste collection calendar

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: villesblg_ca
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: villesblg_ca
```

## How to get the source arguments

No arguments required - the calendar is the same for all residents of Saint-Basile-le-Grand.
