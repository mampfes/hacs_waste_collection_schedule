# Staffelbach

Support for schedules provided by [Staffelbach](https://staffelbach.ch).

Source for Staffelbach (AG), Switzerland.

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: staffelbach_ch
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: staffelbach_ch
```
