# Ittre

Support for schedules provided by [Ittre](https://www.ittre.be/).

Source for Ittre.

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: ittre_be
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: ittre_be
```
