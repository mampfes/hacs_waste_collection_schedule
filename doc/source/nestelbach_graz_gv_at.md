# Nestelbach bei Graz

Support for schedules provided by [Nestelbach bei Graz](https://www.nestelbach-graz.gv.at).

Source for Nestelbach bei Graz.

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: nestelbach_graz_gv_at
```

### Configuration Variables

No configuration arguments are required.

## Example

waste_collection_schedule:
