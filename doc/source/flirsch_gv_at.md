# Gemeinde Flirsch

Support for schedules provided by [Gemeinde Flirsch](https://www.flirsch.gv.at).

Source for Gemeinde Flirsch, Tyrol, Austria.

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: flirsch_gv_at
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: flirsch_gv_at
```
