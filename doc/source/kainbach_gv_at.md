# Kainbach bei Graz

Support for schedules provided by [Kainbach bei Graz](https://www.kainbach.gv.at).

Source for Kainbach bei Graz, Austria (Abfuhrkalender PDF).

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: kainbach_gv_at
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: kainbach_gv_at
```
