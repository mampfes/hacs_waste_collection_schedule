# Malta

Support for schedules provided by [Malta](https://www.wastecollection.mt/).

Nation wide collection schedule for Malta

## Configuration via configuration.yaml

```yaml
waste_collection_schedule:
  sources:
    - name: wastecollection_mt
```

### Configuration Variables

No configuration arguments are required.

## Example

```yaml
waste_collection_schedule:
  sources:
    - name: wastecollection_mt
```
